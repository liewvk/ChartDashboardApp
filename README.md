# ChartDashboardApp

A C# application for creating and displaying interactive chart dashboards.

## Overview

ChartDashboardApp is a dashboard application built with C# that enables users to visualize data through interactive charts and dashboards.

## Features

- Interactive chart visualizations
- Dashboard management
- Data visualization capabilities

## Technology Stack

- **Language**: C#
- **.NET Framework**: Designed for Windows desktop applications

## Getting Started

### Prerequisites

- Visual Studio 2019 or later
- .NET Framework or .NET Core/.NET 5+

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/liewvk/ChartDashboardApp.git
   ```

2. Open the solution in Visual Studio

3. Build the project:
   ```
   dotnet build
   ```

### Running the Application

```
dotnet run
```
